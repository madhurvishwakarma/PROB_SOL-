# LeetCode Practice

This repository is a personal collection of LeetCode problem solutions and algorithm practice.

## Overview

- Focused on solving algorithm and data structure challenges.
- Includes problem-solving code, notes, and test cases.
- Useful for interview preparation and learning.

## Repository Structure

Since this repository currently has a minimal structure, here are the sections you can add as you grow it:

- `solutions/` - directory for problem solutions organized by difficulty or topic
- `notes/` - explanations, insights, and study notes
- `tests/` - unit tests or sample input/output cases

## How to Use

1. Clone the repository:
   ```bash
   git clone https://github.com/madhurvishwakarma/leetcode.git
   cd leetcode
   ```
2. Add or update solutions for new problems.
3. Run tests or execute code depending on your language and setup.

# [Kth largest element in BST](https://www.geeksforgeeks.org/problems/kth-largest-element-in-bst/1)
## Easy
Given a Binary Search Tree. Your task is to complete the function which will return the kth largest element without doing any modification in the Binary Search Tree.
Examples:
Input:
&nbsp;     4
&nbsp;   /   \
   2     9
k = 2 
Output: 4Explanation: 2nd Largest element in BST is 4
Input:
&nbsp; &nbsp; &nbsp; &nbsp;9
&nbsp; &nbsp; &nbsp;&nbsp;  \&nbsp;
&nbsp;  &nbsp;&nbsp;  &nbsp;  10
k = 1
Output: 10Explanation: 1st Largest element in BST is 10
Input:
&nbsp;     4
&nbsp;   /   \
   2     9
k = 3 
Output: 2Explanation: 3rd Largest element in BST is 2
Constraints:1 &lt;= number of nodes &lt;= 1051 &lt;= node-&gt;data &lt;= 1051 &lt;= k &lt;= number of nodes
